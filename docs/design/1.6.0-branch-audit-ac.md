# 1.6.0 branch audit — slice `ac`

Audit of the 103 `origin/delete/keep-*` refs listed in `/tmp/branch-slices/slice-ac`,
against trunk `consolidated/1.6.0` at `897074b56`.

## Method

Ancestry and `patch-id` are both useless here: the trunk was rebuilt (only 3 of 819
branches are ancestors of HEAD) and the 1.6.0 rename waves moved every path
(`busbar-core` → `busbar-kernel`, `busbar-unit-*` → `busbar-kernel-*`, codecs folded,
planes extracted). **Symbols survive renames; paths do not.** So, per branch:

1. `base=$(git merge-base <branch> HEAD)`, then `git diff -U0 $base..<branch>`.
2. From the `+` lines only, extract distinctive identifiers — `fn`/`struct`/`enum`/
   `trait`/`type`/`const`/`static` names, and dotted/underscored string literals ≥6
   chars (error codes, route ids, gate row names). Generic tokens (`new`, `result`,
   `len`, …) filtered out. **2,195 unique symbols** across the slice.
3. Test each against a corpus built from `git archive HEAD` (all **3,862** tracked
   files, contents) **plus** `git ls-tree -r --name-only HEAD` (so path-shaped symbols
   are testable). Archive completeness verified: 3,862 extracted = 3,862 in the tree,
   and `.gitattributes` carries no `export-ignore`.
4. Second signal: every file the branch **adds** (`--diff-filter=A`) whose *basename*
   appears nowhere in the trunk — this catches whole files lost across a rename.
5. Bucket; then open the trunk's copy and read the logic for anything touching
   security, auth, money, egress or crypto.

### Instrument defect found and corrected

The first presence pass used `grep -owF -f <patterns>`. On the 58 MB corpus the local
`grep` (ugrep 7.8.4) returned **zero** matches for `key_handle` while `grep -oF`
returned 43 — `-w` misbehaves at that input size, though it is correct on a small file.
That is exactly the "never conclude from a truncated instrument" failure. The pass was
redone with substring matching (`-oF`), which errs toward *present* and so cannot
manufacture a survivor. Seven symbols moved absent → present
(`contract_transport`, `Frobnicate`, `key_handle`, `m-responses`, `mint_ceiling`,
`resource_template`, `token_auth`). Final: **1,663 present, 532 absent.**
Every headline claim below was then re-verified with an authoritative
`git grep -lF -- <sym> HEAD`.

### Reading the buckets

presence of *any* distinctive absent symbol. Many of the 91 survivors are recuts of
the same stack and carry the same body of work; the **SURVIVORS** section groups them
into the twelve distinct bodies of unlanded work that actually exist. `absent` counts
below exclude gate-census tallies (`cell.N.count`) and planted selftest fixture names,
