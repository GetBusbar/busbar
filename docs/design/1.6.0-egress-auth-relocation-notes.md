### Mint-behaviour contract the migrated assertions preserve (verbatim)

- **jwt claims** (`jwt_claims_json`): scope verbatim; iss/aud/iat/exp placed; `sub` OMITTED when
  subject unset (regression guard — a Google SA treats mere presence of `sub` as
  domain-wide-delegation), exactly `sub` verbatim when set; hostile values serde-ESCAPED not
  spliced; exactly 5 keys (no injected claim).
- **token_uri / token_url SSRF**: https required for a public host (http only loopback/private);
  cloud-metadata/IMDS denied even over https; honors operator posture (allow_all / allow-override /
  extra-deny) — validate == apply.
- **credential parse**: jwt malformed-SA / non-PKCS#8 rejected; oauth `client_id:secret` split on
  first `:` (secret may contain `:`); empty id/secret rejected.
- **`expires_in` tolerance**: integer / numeric-string (ADFS/AAD-v1) / float / decimal-string /
  absent→3600.
- **capped read** (security): a body over the 256 KiB cap is a CLEAR "cap"/"truncat" error, never
  a buffered success or partial parse; a mid-body connection drop is a DISTINCT transport-error
  message (must not read as a cap/truncation error) — proven for both minters via the shared
  `read_capped_token_response`.
- **Redaction**: `{:?}` of `ClientCreds` / `CachedToken.token` shows `[REDACTED]`, never the secret.

### Substrate fixture extension (needed for the transport-error test)

`spawn_http` serves a complete well-formed response and cannot reproduce a mid-body connection
drop. The migrated `transport_error_during_read_is_reported_distinctly_from_truncation` needs a
server that sends a response HEAD advertising a `content-length` but then CLOSES the socket without
the body — hyper surfaces the premature EOF as a transport error (→ `ReadEnd::TransportError`),
matching the old `MockResponse::SseTransportError { ok_events: vec![] }` semantics. Added as a new
`spawn_http_premature_close(claimed_len)` in `egress/fixtures.rs` (test machinery only, gated
`cfg(any(test, feature = "test-support"))`, no change to existing `spawn_http`).
