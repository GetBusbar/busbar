# P05-prior — sweep of 83 files previously *mentioned* in the 1.6.0 sweep corpus

Method: for every file below, ran `git grep -n -F -- "<path>" -- 'docs/design/1.6.0-*.md'`
against all 63 prior `docs/design/1.6.0-*.md` documents (captured to a scratch dump), then for
each hit judged whether it is a **real verdict backed by a command** (a `file-verdicts.md`
LIVE/TEST/TOOLING row with its cargo-dep-info/BFS witness; a MAP/LEDGER/THE-LIST/money-sweep/
unconstructed-sweep/decision-audit row with a concrete command, line numbers and a stated
verdict) or a **bare mention** (a path cited only as the sink column of an unrelated config-wiring
row, a branch-diff "concentrated in" citation, a cross-reference table entry). Where a real verdict
already exists, it is cited by document + row id, not re-derived, per the contract. Where the
corpus carried only bare mentions or nothing, I ran my own checks (shown inline). Additionally ran
`git grep` cross-references against `docs/design/1.6.0-THE-LIST.md` / `1.6.0-LEDGER.md` /
`1.6.0-MAP.md` to confirm which findings already carry a tracking id, so no row here duplicates one
that already exists. One new finding (X-3400) was independently verified by reading source; every
other FINDING verdict below is a citation of a pre-existing, already-tracked corpus row.

Ratchet tail (`qa/*.toml`, plus the `qa/*.json` registries that share the same `qa/` directory):
read-only, per contract — no ratchet was edited or blessed. For each, the question asked was
whether the subject it measures (a path, crate name, or symbol) still exists; where the corpus or
my own check found a ratchet scanning a moved/deleted subject, that is recorded as a FINDING citing
the existing evidence.
