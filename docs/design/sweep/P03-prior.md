# P03-prior — 83 files named by a prior sweep, never given a per-file verdict

**Method.** For every file below: `git grep -n -F "<path>" -- 'docs/design/1.6.0-*.md'` was run first
(full dump kept at the time of writing; all 83 paths returned at least one hit, confirming this slice's
premise). Each hit was read in its source document to decide whether it is a **real verdict backed by a
command** (a grep count, a `git blame`, a gate run, a `cargo` plant, a diff) or a **bare mention** (a
file named in passing while describing something else). Where a prior document already ran the check,
that finding is **reused and cited**, not re-derived — this is why almost every `ROWS` cell below is
`-`: the defect already has a home in `1.6.0-THE-LIST.md`, `1.6.0-LEDGER.md`, `1.6.0-DELETE-LIST.md`, or
a named sweep, and duplicating its X-id would double-count it. Two rows in this slice needed a fresh
command because the two prior mentions of that exact code path **contradicted each other** (one said
FIXED, one said BROKEN) — those two get new X-ids in this slice's own block, `X-3200`/`X-3201`, because
the verification was actually performed here, not carried.

The single heaviest repeat offender across this slice is `docs/design/1.6.0-unconstructed-sweep.md`,
whose findings are all already aggregated into **`THE-LIST.md` X-259** ("400 capabilities declared and
never constructed... 10 sit on the money path"). Every file below with a Shape-1a ("declared,

(the sweep's own docs-exclusion proof and four independent controls are described at the top of that
