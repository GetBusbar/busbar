**5.1** The slot's model is written in its wave-table row. Use it. Do not substitute.
**5.2** The rule that assigned it — 90 opus, 102 sonnet, 52 haiku:

| model | assigned when |

## 6. PUSHING

**6.1** Push `predev` continuously — after every slot. It has no CI and costs nothing.
**6.2** Do NOT push `dev` before Phase 0 exits. `dev`/`qa`/`main` cannot report the required
contexts today; the push buys a meaningless red and burns runner minutes.
**6.3** Push `dev` **once per phase boundary**. Not per wave. 244 wave-pushes is 244 full CI runs.
**6.4** A slot touching **money or the oracle** pushes `dev` **alone**. A batched push destroys
the attribution for a moved byte.
**6.5** Budget: about **15** `dev` runs for the whole release.
**6.6** Ride the train. `predev`→`dev` goes through turnstile. Turnstile denies today
(`busbar-turnstile admit` calls `cargo xtask conformance check --musts`, which does not exist →
exit 2 → deny). Repair it in Phase 0.
**6.7** NEVER push `dev` by hand to route around a turnstile denial. A denial you bypassed is a
gate you deleted.
**6.8** NEVER push `qa`. NEVER push `main`. A push to `main` cuts a release — tag, GitHub
Release, container promotion, `latest` moved. Irreversible.

## 7. MONEY

**7.1** Money is binary. A bank auditor passes it or does not. If not, it is wrong. Fix it.
**7.2** Do not ask about money. Be right about it.
**7.3** Ledger ≠ money. Planes write the ledger; money is a view on the ledger × the ratecard.
**7.4** The ledger is exactly what the plane did. If it sent 17 output tokens, it sent 17.
**7.5** Money is never wrong. The ledger or the ratecard is wrong. Fix that.
**7.6** NEVER self-approve a billed byte that moved. PARK it with cell, diff, root cause and
recommendation, and stop.

## 8. THE ORACLE

**8.1** The oracle is never waived.
**8.2** NEVER bless, re-record or regenerate a golden, an `accepted-differences.json` entry,
an `openapi.json`, or a `qa/*.toml` ratchet.
**8.3** Customer-visible behaviour stays identical to 1.5.5 unless the owner signs off a named
change with a reason.

earlier session; a bare `git commit` sweeps them into yours.
**9.4** NEVER `git commit --amend` in the shared checkout.
**9.5** Snapshot before any delete.
