# 1.6.0 ABI Solidification — Capability Matrix, Gaps, and the Gate to Freeze

**Status: PROPOSED / synthesis (2026-08-19).** Result of enumerating every core capability LLM/MCP/A2A
exercise today + a deliberate **VPN stress-test plane**, mapping each to a neutral ABI seam, under the
owner rule *core is core, protocols are plugins* and the decision rule *2+ planes need it → core; 1 →
that plugin.* Companion to `1.6.0-protocol-plugin-abi.md` (the ABI) and
`1.6.0-foundation-what-features-reveal.md` (the thesis + rules).

> Unattended rulings: decisions surfaced by the design passes are resolved here with the recommended
> default and marked **[RULED]**; assumptions noted. Owner overrides any.

---

## 0. HEADLINE VERDICT — NOT YET FREEZABLE (and that is the valuable finding)

The neutral spine is **real and correct** — 19 seams, each witnessed by 2+ planes, so the ABI's
*design* satisfies the decision rule for everything already extracted. But freezing now would bake in
**three structural incompletenesses**, and the VPN column proves the second is not hypothetical:

1. **The plugin→host inbound direction does not exist yet (G2).** Every "✓" seam is reachable only
   *compiled-in*; across a `dlopen` boundary a plugin cannot call back `govern_admit`/`meter_charge`/
   `journal_append`/`egress_open`/… You cannot freeze an ABI whose inbound half is unbuilt.
2. **Chat/request-response assumptions are load-bearing in "neutral" shapes (G6–G9, G14).** The VPN
   plane — packet-oriented, duplex-forever, byte-metered, no request/response, no roles/turns — proves
   that `PlaneFacts::Shape`/`Role`, the *terminal* disposition classifier, the *bounded-buffer* codec
   unit, and the *HTTP-path* ingress are **LLM-only shapes masquerading as neutral.** Freeze them and
   no non-request-response plane is ever possible.
3. **Two 2+-plane primitives are designed-but-unwired (G1 itemized cost, G4 cross-plane lineage)** —
   both needed by MCP+A2A *today*, not in the future.

**This reframes 1.6.0:** it is not "extract the plugins on the current ABI." It is "**harden the ABI to
freezability (G1–G11), proving it against a non-LLM plane, THEN extract on the frozen seam.**" The
extraction rides on top of a solid wall — not the other way around.

## 1. THE SOLIDIFIED NEUTRAL SPINE (confirmed core — 2+ planes each)

These ride ONE neutral mechanism reached identically by every plane that needs them. This is the ABI
surface that is *already* right:

route/member-key · PlaneDecl registry (fn-ptr `install_planes`) · failover walk (pin/repeatable/
exhaust) · circuit breaker per member · disposition classifier (Stage-2 neutral) · budget reserve→
settle over a group tree · rate windows · concurrency (AdmitGrant RAII) · audit chain+digest · authz
`Grant::Scope{kind,name}` · admission/RFC-8707 · metrics label-passthrough · lifecycle (hydrate/start/
on_swap) · config seam (`PlaneCfg`) · catalogue · codec Reader/Writer (opaque IR) · secrets-by-ref
(design) · egress-by-pool (design) · session identity at ingress.

All four planes (LLM/MCP/A2A/VPN) route, register, breaker, authz, audit, and meter through the *same*
seams — that is the proof the core generalized correctly.

## 3. THE ORDERED GATE TO FREEZE (dependency-first)

Freeze when **1–9 land and pass across a `dlopen` boundary with at least one non-LLM plane** (MCP or
A2A extracted; VPN skeleton compiling). 10–11 may trail as post-freeze hygiene if their seams are
already neutral-shaped.

1. **G2 — inbound host vtable** (`busbar_set_plane_host`). Unblocks everything; nothing is testable
   across the boundary without it.
2. **G13 — genericize Store/ScopeRef/PlaneCfg** to opaque per-plane records. Deleting a plane must
   touch no core trait; every schema-move depends on it.
3. **G6 — neutral PlaneFacts** (opaque author-label + Slot + Shape). Detaches gate/router/tap from
   `IrRequest`; precondition for G7/G9 and any non-chat plane.
4. **G1 — itemized CostBreakdown reserve→settle.** Wire MCP+LLM; move token pricing to busbar-llm.
5. **G4 — cross-plane correlation id (B).** Needed the moment A2A `covers_downstream_l2_spend` + MCP
   sampling exist (both do).
6. **G5 — session substrate (A).** Folds A2A taskstore; homes VPN tunnels; enables stateful affinity.
7. **G3 — inter-plane dispatch host-call.** Removes MCP's reach into `ingress::operation_resolved`.
8. **G10 + G11 — enrich `egress_open` + secrets-by-ref/host-sealer.** Last place plane-specific
   outbound logic leaks into core.
9. **G7 + G8 + G9 + G14 — duplex streaming, streaming codec unit, continuous disposition, non-HTTP
   ingress.** The VPN-class generalizations; land together so the ABI is proven against a
   maximally-unlike-LLM plane *before* the shapes freeze.
10. **G12 + G15 + G16 — `write_models`, Order-trait cleanup, handlers IR cleave.** Extraction hygiene.
11. **Resolve the quarantine watch item** (demoted per §2).

## 4. GROWTH-FOUNDATION BUILD ORDER (the primitives, which ARE gaps above)

From the growth design pass. **Mechanism CORE, payload opaque, owned per-writer** — the invariant
across all of them.

- **Q6 (=G13 scope half)** — leaf, tiny (**S**), no deps/dependents. Genericize `ScopeRef` wire to a
  kind-keyed map; delete the `mcp_*` constructors; drive kinds from `PLANE_DECL.scope_kinds`. *Also
  fixes a live bug: A2A "agent" grants cannot round-trip today.* **Start now.**
- **A — session substrate (=G5)** (**L**) — prerequisite only for its own tenants (incremental scan,
  cache-affinity, taskstore fold-in). Orthogonal to B.
- **B — request lineage (=G4)** (**M**) — prerequisite for cost *trees* + tracing. Generalizes the
  existing `next_request_id()` u64.
- **cost-analytics (=G1 wiring)** (**M**) — cheap layer (per-tool-CALL) needs neither A nor B; deep
  layer (per-LLM-request trees) needs B. Forward-compatible by carrying an opaque correlation dim.
- **C — `write_models` (=G12)** (**S/M**) — independent; design was cut off in the pass (re-run
  pending), but the /v1/models investigation already scoped it: add `write_models` to `ProtocolWriter`
  (default OpenAI shape), move envelopes to dialects, resolve via the same fingerprint as chat.

**Recommended landing sequence:** Q6 → A + gate incremental-scan → cost-analytics cheap layer → B →
cost-analytics deep layer. A and cost-analytics-cheap can proceed in parallel. (This is a *subset* of
the freeze gate §3; the full freeze also needs G2/G3/G7-G11.)

## 5. THE STATE FORK — RULED once, for both A and B

**[RULED] IN-PROCESS-FIRST** (per-replica, ephemeral, bounded) **with SAFE DEGRADATION; durability is a
per-tenant write-through the owner drives; a Store-backed shared impl is a specified SEAM, not built.**
Mirrors how affinity already chose statelessness, and matches taskstore's shape (in-mem working set +
optional `PlaneStore` write-through). A cold/evicted/cross-replica slot → the consumer falls back to
its stateless path (full re-scan, pure-hash affinity, independent metering) — **never wrong, only less
optimized.** A2A tasks keep their durable write-through unchanged.

*Assumption:* cross-replica session continuity / cross-instance distributed lineage is **not** a 1.6.0
product requirement — safe degradation is acceptable until measured. **This is the one fork most worth
an owner confirm** (it's the only one with a product-shaped answer); everything else below is
engineering detail I've ruled.

## 6. UNATTENDED RULINGS on the surfaced decisions

Taking the recommended defaults (all well-reasoned and reversible); owner overrides any.

- **[RULED] D2 eviction/pinning (A):** per-slot "pinned, explicit-removal-only" flag; A2A active slots
  exempt from LRU (prevents the `evict_terminal` two-chains corruption).
- **[RULED] D3 keyspace (A):** keep per-tenant keyspaces (session_id_hash for gate/LLM, task_id for
  A2A) — least-breaking; a session→tasks index is a later additive.
- **[RULED] D4 slot identity (A):** session_id_hash generally; **wider/salted hash for the gate.screen
  tenant** so a 64-bit collision can't let session A skip-screen with session B's cleared set
  (security-adjacent).
- **[RULED] D5 lifecycle bound (A):** both TTL and LRU, hard-capped (reuse `key_gauge_limit` shape) —
  unbounded per-session slots is a memory-safety hole.
- **[RULED] D6 lineage trust (B):** mint fresh root unless the peer is trusted (mTLS/signed); never
  adopt a forgeable caller-supplied root (parallels core-minted-grants). 
- **[RULED] D7 lineage vocab (B):** distinct `root_id`/`parent_id` — a different axis from the internal
  span tree; do not conflate with export `TraceId/SpanId`.
- **[RULED] D8 causer threading (B):** explicit `RequestCtx` threading; no hidden task-local (matches
  the codebase's explicit-request_id discipline; avoids failover/spawn bleed).
- **[RULED] D9 cardinality (cost):** plane-DECLARED label allowlist (`PlaneDecl.cost_dims`, bounded at
  load like `verbs`) + operator-configured value allowlist; overflow → `dim=other` bucket.
- **[RULED] D10 cost surface:** durable admin-JSON first (cross-replica correct, no cardinality risk);
  gate the Prometheus series behind the allowlist.
- **[RULED] D11 durable metering schema:** defer named columns; ride cost components on the
  opaque-per-plane-record generalization (G13) rather than a 4-plugin column fan-out now.
- **[RULED] D12 cost header default:** opt-in, absent by default (like `x-busbar-route-*`) — avoid a
  pricing-granularity leak.
- **[RULED] D13 honest granularity:** cost ships per-tool-CALL only, labeled honestly; per-LLM-REQUEST
  trees explicitly deferred to B; carry an opaque correlation dim now for B to fill.
- **[RULED] D14–D17 Q6:** wire key `allowed_scopes_by_kind`; keep `allowed_pools` as the frozen legacy
  named field (preserve byte-identity) with all other kinds in the map; api persists any kind string
  opaquely (validation lives in core against `PLANE_DECL.scope_kinds`); land the wire genericization
  first (fixes the a2a-agent round-trip bug), add non-pool grant PRODUCERS + admin surface with the
  plane extractions.
- **[RULED] D18 / C:** commission the `write_models` design (re-run) before sequencing C; the /v1/models
  investigation already scopes it, so it's low-risk.

## 8. Hardening pass — buildable verdict, freeze-blockers, hole-map (owner: "agreed all around")

The C-boundary is **buildable as designed**; the freeze-blockers are uncut protocol-names in the
spine + Store ABI and the uncut IR edge — not the C-ABI shape.

**Confirmed real:** the 8th optional symbol `busbar_set_plane_host` loads **without a
`TRANSPORT_VERSION` bump** (exact `busbar_set_log_sink` pattern; handshake checks only the 6 required
symbols; signing enumerates no symbols → already-signed plugins keep loading). **Copy-out transport is
the status quo** (`to_vec()`+`free_guarded`, cap-checked) — PlaneBorrow correctly deferred. Inbound
`HostCall` has a working precedent (`host_log_sink`: `extern "C"`, whole-body `catch_unwind`, never
derefs a plugin pointer). **Caveat (corrected in the ABI doc §5.2):** soundness properties 2/3/4/5 are
**net-new/unbuilt** — only the boundary *shape* has precedent, not the token-slab/lock-invariant/grants.

**FREEZE-BLOCKERS (all RULED per owner "agreed all around"):**
- **FB-1 Store names protocols** → genericize to **~8 generic ops** (append-chained + collision policy,
  put/get/delete-by-key, list-by-kind, distinct-key-enum, ts-purge, atomic test-and-set) — **not** the
  §6.1 3-method sketch (it silently drops get/delete/distinct/purge/test-and-set). Rows cross as a
  neutral **`ChainedRecord{chain_key,seq,ts,prev_hash,hash,body}`** envelope (backends need indexed
  chain columns), **unified with the existing audit chain** (don't invent a 2nd envelope).
- **FB-2/FB-3 token model + `mtok` in the spine** → `CostModel`/`RateNanos`/`TierTokens`/`*_mtok` move
  to busbar-llm; core keeps the neutral `CostBreakdown` ledger. *(Fixed the ABI-doc step-1c that
  wrongly said they can't move.)*
- **FB-4 TierTokens doc contradiction** → **RULED §4.3.1/Q6 governs**; step-1c corrected;
  `UsageLedger`/`MeteringDelta` genericize with the Store rather than staying as named LLM tiers.
- **FB-5 concrete IR still in core** (busbar-llm reaches *up* into `busbar_core::ir` **2599×**) → gated
  on the §8 translation-layer move (dependency inversion), not a mod decl; the test-support `#[path]`
  re-link keeps ~218 IR-naming core tests green through the move.
- **FB-6 `DEFAULT_PROTOCOL = PROTO_ANTHROPIC`** → registry-supplied default, no core const.
- **FB-7 soundness property 4 asserted-but-absent** → **RULED** author the `structure-lint.sh` row +
  per-token depth-1 counter *before* the vtable lands. *(Fixed the ABI-doc overclaim.)*
