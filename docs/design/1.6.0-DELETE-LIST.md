## THE BAR — held absolutely

A delete is a claim that **nothing is lost**. An unproven delete destroys work. Every row must clear
all six:

1. **Only NO-GAP evidence qualifies.** An **ADJUDICATE** row is **not deletable**. Absent-by-name
   with the behaviour unread is a question, and a sweep already proved why: `SessionDriver`/
   `DuplexWire` read as absent while `SessionPump`/`SessionLease`/`SessionView`/`DuplexReader`
   carried the same seam, and a test absent by name turned out proven on trunk **under a different
   name with a stronger guard**.
2. **"Bulk superseded" is not a proof.** One sweep graded **94 branches** that way and then
   spot-checked exactly one — `keep-auth-e` — which **promoted to a real auth GAP**. That single
   case invalidates the label for all 94 until each is certified per-symbol.
3. **The docs trap, in reverse, is lethal here.** **6,503 identifiers exist on trunk only in
   documentation and in zero code files.** A symbol found "on trunk" in `docs/` is a symbol that is
   **NOT in the product**. Search excluding docs; justify including them. Conversely
   `docs/design/xtask-gates.md:1422` saying `UNSCORED_SOURCES` and `SPEC_SINK` *"are gone"* is a
   deliberate retirement and **IS** a valid delete justification.
4. **Blast radius before READY.** A doc a gate READS is not deletable. `xtask/src/gates/no_deferral.rs:60`
   pins `1.6.0-TRACKER.md` as `const TRACKER`, `:310` fails the `waiver-shape` row outright if it
   cannot be read, and `:346` requires every waiver's `expiry` id to resolve to a row in that file.
5. **A delete can UNCOVER a finding.** One sweep struck 2 of 24 audit scopes with evidence and found
   that a struck scope had held **three source-scanning confinement guards that are absent from the
   tree** while `on_upgrade` is still declared in three production files. **That is a TODO row, not
   a delete row.** Every executed delete gets re-checked for what it exposed.
6. **A rename is not a death.** See **REFUSED R-1** below: a crate the census called deleted is
   live under a different directory, and striking its rows would have erased the record of an
   owner-locked decision.

### Row schema

| field | rule |
|---|---|
| **SUBJECT** | the branch, file, crate, ratchet row, audit scope, waiver, gate row, or doc |
| **KIND** | branch · file · crate · ratchet-row · audit-scope · waiver · gate-row · doc · ledger-row |
| **PROOF OF CLEAN** | the command and its output showing nothing is lost. Not "looks superseded" — *shown* superseded. |
| **WHERE IT LANDED** | for anything superseded, the symbol or behaviour on trunk that replaced it, **by name** |
| **BLAST RADIUS** | what reads this thing today |
| **READY** | **YES** (safe to delete on the owner's word) · **NO** (say what is missing) |
