# 1.6.0 branch audit — slice `af` (103 branches)

Trunk audited against: `consolidated/1.6.0` @ `897074b56` (`HEAD` at the start of this pass; other
agents advanced it during the run — every grep below was re-run against live `HEAD` and every match
found **only** inside a sibling `docs/design/1.6.0-branch-audit-*.md` was discarded as not-trunk).

## Method

Per branch: `base=$(git merge-base origin/<b> HEAD)` → `git diff $base..origin/<b>` → extract every
added declaration name (`fn`/`struct`/`enum`/`trait`/`const`/`static`/`type`/`mod`/`macro_rules!`)
→ set-difference against an exact-token index of the whole trunk (79 450 distinct tokens over 3 692
source files: `crates xtask scripts docs qa testing conformance examples tests fuzz bin .github`).
Word-boundary `git grep -w … HEAD` re-confirmed every candidate, and for every
security/money/egress/crypto hit the trunk's own copy was **opened and read** — several "missing"
symbols turned out to be renames whose behaviour is present (`RATE_WINDOW_SECS` →
`PUSH_RATE_WINDOW_SECS`, `DIGEST_SCHEME_LEN_PREFIXED` → `AUDIT_SCHEME_LENGTH_PREFIXED`,
`token_count` → `read_count_u64`), and several "present" symbols turned out to be trunk text that
does **not** do the thing (see §Survivors).

### The shared `integration/rc-consolidated` segment

42 of the 44 `land/*` branches plus `integration/reland` all descend from **`e7ecaf0fb`**, the tip
of `integration/rc-consolidated`. `git merge-base` puts them all at `dc7bb3233`, so **every one of
their diffs contains the 11-commit `dc7bb3233..e7ecaf0fb` segment**. That segment is audited once,
below, and it is **not clean** — so under the strict rule (*"one or more distinctive symbols are
absent"*) all 42 bucket as SURVIVOR. The `evidence` column therefore says whether the loss is the
branch's **OWN** or **INHERITED** from that shared segment, so a branch that contributed nothing new
is still distinguishable from one that did.

`{target, method, authority, peer, body}` with `#[derive(Clone, Copy, Debug)]`. The branch adds
`credential`/`accepts`/`media` (whole, scheme word included — interpretation is the auth chain's,
not the transport's), a `pub mod presented { CREDENTIAL, ACCEPTS, MEDIA }`, those three keys at the
head of `MOUNT_FACTS` (so a declaration's capture cannot shadow what the caller actually presented),
and a **hand-rolled `Debug` that redacts `credential`** while keeping `None` as `None`, so the
redaction never manufactures a presented credential out of an absent one.

Net effect in trunk: a plane mounted on the generic HTTP transport **cannot read what the caller
presented** — not as a fact, not by any name. (The redaction half is moot in trunk precisely because
the field does not exist; it becomes load-bearing the moment the field lands, which is why both
halves belong together.)

## Caveat on depth

Every branch was scanned and bucketed, and every symbol reported as absent was confirmed by
word-boundary `git grep` over live `HEAD` with sibling audit reports excluded. For the
security/money/egress/crypto findings above I additionally **opened the trunk's own copy and read
the logic** (`banned_for`, `chat_body`, `catalogue.rs::server_entry`, `migrate.rs`, `pack.rs`,
`jwt_bearer.rs`, `stdio.rs`, `mount.rs`, `docker.yml`, `net.rs`, `chain.rs`, `ratelimit.rs`,
`pushback.rs`, `usage_count.rs`, `scratch.rs`, `identity.rs`, `verb_store.rs`) — which is what
caught the four cases where the *spelling* was absent but the *behaviour* is present (NAT64,
ratelimit sweep, a2a push limiter, token-count doubles), and the one case where the behaviour is
absent while the enabling function is present and dead (§S15).

For the six very large branches — `queue-rebased-A3plus` (334), `perf/1.6.0-plugin-abi-measurement`
(262), `delete/keep-vocabulary-longest-match` (245), `r32c-mcp-units` (229), `r4-0c-llm-mount` (210),
`r31h-a2a-boot` (200), `qa` (194), `predev`/`land/oracle-rebless-full` (187),
`gate/audit-2consecutive-zero` (167) — absence was established mechanically for all symbols, but
per-symbol behavioural reading was **sampled, not exhaustive**. Their SURVIVOR verdict is sound; the
per-item severity within them is not fully characterised.
