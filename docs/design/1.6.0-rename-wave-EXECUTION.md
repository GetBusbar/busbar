# busbar 1.6.0 — in-tree rename / dissolve wave: EXECUTION CHECKLIST

> **This is an execution checklist, not a spec.** It maps every CURRENT workspace crate to
> its locked end-state and gives the safe order to get there. The authority is
> `docs/design/DECISIONS.md` rows **#33–#40** (with the `busbar-core` drain detailed in
> `docs/design/1.6.0-composition-root-plan.md` **§4.1**). Where the DECISIONS do not lock a
> specific crate's destination, this doc says **OPEN — for the dictator** and does NOT guess.
>
> SCOPE = the **in-tree** wave only: `git mv` + Cargo-repoint + module-merge, run as ONE atomic
> wave once the open codeaudit-fix branches fold (#34 TIMING). The **external GitHub repo
> renames + the extraction of plugin crates to their own repos** (#31/#39) ride the
> release-train wave, NOT this one — so plugin instances are *renamed in place* here and
> *moved out* later.

## 3. Dependency order (safe execution sequence)

Rule: absorb into a crate BEFORE deleting the source; rename a crate BEFORE repointing its
dependents; keep the workspace green — no broken intermediate state longer than one commit. The
`busbar-core` drain is exempt from ordering: #27(b) puts each engine step behind a per-step
re-export facade in `busbar-core`, so those relocations land in ANY order.

- **Phase A — vocab into `busbar-contract`** (leaf-most; nearly everything deps contract already):
  fold `busbar-caps`, `busbar-grammar`, `busbar-timing`, `busbar-contract-transport`,
  `busbar-plugin` (spec) into `busbar-contract`; repoint every consumer edge → `busbar-contract`.
- **Phase B — plugin infra**: fold `plugin-sign` + `plugin-pack` → `plugin-loader`;
  `plugin-testkit` → `plugin-sdk` (feature). Repoint consumers.
- **Phase C — `busbar-api` retire**: relocate sealed ABI → contract, money records →
  (staged onto) `kernel-ledger`; repoint all api consumers. **Oracle gate here** (money-path).
- **Phase D — substrate split**: `busbar-substrate-values` → `busbar-core-substrate` (mv);
  drain fat `busbar-substrate`; repoint.
- **Phase E — units → kernel-8** (leaf units first): `breaker`, `wal`, `audit`, `scope` (no
  intra-unit deps) → their kernels; then `kernel-ledger` (merge cost+usage+ledger),
  `kernel-budget` (admission), `kernel-egress` (merge egress+trust), `kernel-identity` (merge
  auth+egress-auth). `unit-verbs` → `core-admin`; `unit-transport-key` → OPEN dest.
- **Phase F — core tier**: `busbar-admin` → `busbar-core-admin` (absorb verbs + plane-admin);
  `busbar-oauth2` → `busbar-core-oauth2`; delete `busbar-core` (drain complete);
  `busbar-core-config` → binary; `busbar-core-hooks` split.
- **Phase G — planes**: fold codecs/hosts/engines into the 4 `busbar-plane-*`; voice trio →
  `busbar-plane-streaming`.
- **Phase H — plugin instances**: `auth-static-plugin` → `busbar-auth-static`; `hooks-ranking` →
  `busbar-hook-ranking`. (transports/store-memory: names already conform.)
- **Phase I — binary last**: `crates/busbar` repoints every changed edge; resolve examples.

## 5. RISK notes

**Money-path crates — REQUIRE the shadow oracle byte-green after the move (bin/oracle direct,
#29):**

- **`busbar-api` retire → `busbar-kernel-ledger`** (Phase C). Highest risk: `VirtualKey`'s
  HAND-written `virtual_key_wire` module + `UsageLedger`/`MeteringRow`/`AuditRecord`/`PlaneRecord`/
  `CredentialSecret` relocate **module-path-ONLY** — serde field names / wire bytes must not
  change (#35 BYTE-IDENTITY GUARD). Oracle-gated.
- **`busbar-kernel-ledger`** (merge of cost+usage+ledger) — the book; rates+usage+ledger topology
  moves. Oracle after.
- **`busbar-kernel-budget`** (admission) — `try_admit`/`refund_request`, the D7 check-then-charge
  (parity clause). Oracle after.
- **`busbar-kernel-audit` / `busbar-kernel-wal`** — the one append-only chain + append primitive
  (ledger AND audit ship through wal). Audit-record byte shape is oracle-checked.
- **`busbar-core` `governance/` + `cost.rs` + `plane/` drain** — money furniture; oracle each step.
- **`busbar-substrate` drain** — carries `billing`/`catalogue`; oracle after runtime relocation.
- **`busbar-kernel-egress` (+trust)** — swrr weighting + `net_guard` over `VerifiedDestination`
