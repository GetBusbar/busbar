# 1.6.0 — Branch corpus sweep ledger

Half-here-half-there: code that exists on a branch and **not** on trunk.
Trunk pinned at `d2548391bc3a76b4a01c3dfa4c486efebe93a172` (`consolidated/1.6.0`).

Six agents append to this file. **Append only. Never rewrite another agent's rows.**

Method (settled): per branch, versus its merge-base with trunk, extract the symbols the
branch ADDS (identifiers, test names, string literals) and search trunk for each — **with
`docs/` and every `*.md` EXCLUDED**, because an audit document describing a gap is prose
about missing code, not the code. `patch-id` is useless (the rename waves moved every path)
and ancestry is useless (3 of 819 branches are ancestors of HEAD). Symbols survive renames;
paths do not. Dedup by `(path, blob)`.

Buckets: **EMPTY** (no source content trunk lacks) · **HARVESTED** (every unique symbol on
trunk, possibly at a renamed path) · **SURVIVOR** (one or more symbols absent from trunk).

Verdict grades used on SURVIVOR rows:
`GAP` real missing work · `SUPERSEDED` trunk implements the same behaviour under another
design/name · `TEST-ONLY` only test names/assertions absent · `PARK` money path, needs a
named owner before anything moves.

## Slice: `origin/delete/*`, rows `NR%3==1` (170 branches) — agent `da`

Derived deterministically:
`for-each-ref refs/remotes/origin | grep '^origin/delete/' | sort | awk 'NR%3==1'` → 170 branches.
Trunk pinned at `d2548391bc3a76b4a01c3dfa4c486efebe93a172`; re-checked at the end of the sweep.

**Instrument.** Trunk was indexed once into three disjoint tiers — `code`, `docs` (`docs/**` +
every `*.md`) and `qa` (`qa/**`, goldens, waivers, shadow-oracle). "Present on trunk" means
**`code ∪ qa`; `docs` is NEVER counted.** Per branch, the diff against its merge-base yields
definition-site symbols and string literals on ADDED lines; a symbol counts as *branch-authored*
only if it is absent from the merge-base tree (45 distinct merge-bases, each indexed) and is not
also on a removed line — without that subtraction, rename-driven file moves read as thousands of
false additions.

**Bucket distribution (170):** SURVIVOR 142 · EMPTY 17 · HARVESTED 11.
Refined verdicts: BULK-SUPERSEDED 94 · REVIEW 39 · TEST-ONLY 7 · AUDIT-BOOKKEEPING 2.

**Docs-exclusion proof — it changed answers in this slice, repeatedly.**
6,503 identifier tokens exist on trunk in `docs/` but in no code file. Across the slice,
**2,145 symbol/string occurrences on 119 of 170 branches** would have read as "present on trunk"
had `docs/` been searched. Named instances, each verified by hand with
`git grep -w <sym> <TRUNK> -- ':(exclude)docs/'` returning 0 files while the `docs/`-only search
returns ≥1: `CredentialSignature`, `CredentialArrival`, `CredentialPresentation`, `SigningParams`
(whole design, `docs/design/1.6.0-credential-signature-declared.md`, **zero code**);
`RequestHeaders`; `WIRE_HTTP`/`WIRE_STDIO`; `refusal_answer`; `credential_refusal`;
`group_bucket_windows`; `EXPECTED_UNWIRED`; `WiringArm`; `lane_in_pool`; `HostShaped`;
`webpki_client_config`; `KeyRowsRefused`; `CatalogueEntry`; `KeyScope`; `BootFold`.

**Zero control.** Every "absent" verdict was controlled against symbols known present on trunk
using the identical query shape. Index controls: 12 positive (`AccrualMeter`, `AdminAuthChain`,
`interpolate_env`, `reject_yaml_unsafe_value`, `AdminMountSeam`, `splice_occurrences`, …) all
True; 3 negative all False. Shell controls: the same `git grep -c -w … | wc -l` loop that
returned 0 for the survivors returned 21 for `AccrualMeter`, 6 for `AdminAuthChain`, 4 for
`OPENING_CHECKPOINT_SEQ`. Two false-zero traps were hit and fixed during the sweep: zsh parsed
`"$T:crates/…"` as a `:c` history modifier (fixed to `${T}:`), and an early run tested
branch-side `qa/` manifest content against a **code-only** trunk index, manufacturing false
survivors (3 of 4 sampled auditor ids were in fact on trunk in `qa/audit-ledger.json`) — fixed by
making presence `code ∪ qa`, then re-running all 170.
