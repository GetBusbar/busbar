# 1.6.0 — Branch corpus sweep ledger

Half-here-half-there: code that exists on a branch and **not** on trunk.
Trunk pinned at `d2548391bc3a76b4a01c3dfa4c486efebe93a172` (`consolidated/1.6.0`).

Six agents append to this file. **Append only. Never rewrite another agent's rows.**

Method (settled): per branch, versus its merge-base with trunk, extract the symbols the
branch ADDS (identifiers, test names, string literals) and search trunk for each — **with
`docs/` and every `*.md` EXCLUDED**, because an audit document describing a gap is prose
about missing code, not the code. `patch-id` is useless (the rename waves moved every path)
and ancestry is useless (3 of 819 branches are ancestors of HEAD). Symbols survive renames;
paths do not. Dedup by `(path, blob)`.

Buckets: **EMPTY** (no source content trunk lacks) · **HARVESTED** (every unique symbol on
trunk, possibly at a renamed path) · **SURVIVOR** (one or more symbols absent from trunk).

Verdict grades used on SURVIVOR rows:
`GAP` real missing work · `SUPERSEDED` trunk implements the same behaviour under another
design/name · `TEST-ONLY` only test names/assertions absent · `PARK` money path, needs a
named owner before anything moves.
