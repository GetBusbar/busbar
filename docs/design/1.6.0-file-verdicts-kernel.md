2. **Module graph.** Every `mod` declaration in the crate was resolved, `#[path]` and `#[cfg]` included. Result: **only 2 of 398 files are not reachable from `lib.rs`**, and both are the TRASH rows.
3. **Caller probes.** For every module with a suspiciously low reference count, the module's own public symbols were counted across all production `.rs` files in the workspace with tests excluded. That is how the five unconstructed capabilities below were separated from the merely quiet ones.
