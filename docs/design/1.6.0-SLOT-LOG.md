# SLOT LOG

One row per slot, appended when the slot finishes. This is the only status channel
(rule 15.8 of `docs/design/1.6.0-KICKOFF.md`) — there is no other place a slot reports.

`verdict` is per item: **FIXED** · **STRUCK** (with the measurement that refuted it) ·
**PARKED** (money changed, see `1.6.0-PARKED/`) · **BLOCKED** (names the slot it waits on).

`RED proof` is the command and its non-zero exit, captured in the slot's own pinned worktree
per rule 16.2 — not in the shared checkout, where another slot's write invalidates it.
