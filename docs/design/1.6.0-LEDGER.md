# BUSBAR 1.6.0 — THE LEDGER

**There are exactly two documents in this release.**

| file | answers | authority |
|---|---|---|
| `BUSBAR-1.6.0.md` | *How is this built?* — Laws, the 78 locked decisions, the seams | **THE SPEC.** Part 1 > Part 3 > Part 2 > Part 5 |
| `1.6.0-LEDGER.md` (this file) | *What is left, and who is on it?* | **THE WORKLIST.** One row per open item |

Everything else under `docs/design/1.6.0-*.md` is **SCRATCH**: an audit writes it, its rows
are folded in here, and **the scratch file is then DELETED**. A scratch file that survives its
fold becomes tomorrow's stale doc that misleads the next agent — that is the disease this
structure exists to cure. Twenty parallel documents is how a release stops knowing what it is.

**ONE EXCEPTION, MEASURED, NOT ASSUMED — `1.6.0-TRACKER.md` IS NOT SCRATCH.** It is read by a
gate at run time: `xtask/src/gates/no_deferral.rs:60` pins it as `const TRACKER`, `:310` fails the
`no-deferral:waiver-shape` row outright if it cannot be read, and `:346` requires every waiver's
`expiry` id to resolve to a row **in that file**. Deleting it turns the no-deferral gate red on
every commit. It was listed in THE FOLD in error; it is struck from that list below and stays.

## THE ROW SCHEMA

```
ID | ITEM | WHERE | CLASS | STATUS | OWNER | EVIDENCE
```

* **CLASS** — `money` · `security` · `gate` · `test` · `doc` · `branch` · `engine`
* **STATUS** — `OPEN` · `IN-FLIGHT` · `DONE` · `PARKED-OWNER` · `DEAD`
* **EVIDENCE** — a command, a commit, or a file:line. Never a claim without one.

Ordering is by CLASS: **money first, then security**, then the rest. That is the Laws' order
and it is not negotiable.

### Three rules for every row

1. **A row without EVIDENCE is not a row.** "Looks fine" is not evidence; a command someone
   else can re-run is.
2. **A gap and a failure must never be the same output — and neither may a gap and a success.**
   If a check could not run, its row says `ABSENT`, never `DONE`.
3. **Never self-approve a billed-byte change (#10/#59).** Money defects go to `PARKED-OWNER`
   with cell, diff, root cause and recommendation. The owner signs, not the agent.

### A fourth rule, for this file only: **a copied claim stays a copied claim**

Rows folded from an audit carry that audit's evidence, not this file's endorsement. Where two
audits contradict each other **both** are recorded and the contradiction is flagged in the row.
Where an audit asserted something with no evidence, the row says `EVIDENCE: none given` rather
than inheriting the assertion as fact.
