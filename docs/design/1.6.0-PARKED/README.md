# PARKED — money figures that changed, awaiting the owner

One file per parked item, named `<item-number>.md`, written under rule 15.4 of
`docs/design/1.6.0-KICKOFF.md`.

A money figure that changed is never self-approved. It is parked here with four things and
nothing less:

| | |
|---|---|
| **cell** | which measurement, on which case |
| **diff** | the old figure and the new one, exactly |
| **root cause** | why it moved — in the ledger or in the ratecard, because money itself is never wrong |
| **recommendation** | what you would do, stated plainly enough to be agreed or refused |

An empty directory is the correct state. A file here is a stop, not a note.
