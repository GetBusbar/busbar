**Base** `b0c5b6f1b` (selftest budget: both twins re-measured after the round-two LOCK).
**Input** the 115 commits of `b0c5b6f1b..e161eb290` (the five re-picked queue lines

**Output** `keep-queue-triage` — a linear series on `b0c5b6f1b`.

## 1. The rule this table applies

Deletion-first. `busbar-core`, `busbar-a2a`, `busbar-llm`, `busbar-mcp`, `busbar-voice` and
`busbar-api` (`crates/api`) are scheduled for deletion (see `D33-legacy-retirement.md`). A commit
whose *value* — the behaviour it adds and the cells that prove it — lands in one of those crates is
work into a crate that will not exist, so it is **DROPPED**, and what it carried is recorded here so
the deletion list can inherit the requirement.

Three classes, and the class is decided by where the **behaviour** lands, not by where a line lands:

* **LEGACY-BOUND** — the added lines that carry the behaviour are in a crate on the deletion list.
  Decision: **DROPPED**.
* **NEW-ARCH** — contract / caps / kernel / units / planes / dialects (including the `*-codec`
  crates' `src/ir/` dialect paths) / transports / substrate / the composition root `crates/busbar` /
  `xtask` / `qa` / `scripts` / `testing` / `docs` / the plugin tooling crates. Decision: **KEPT**.
* **MIXED** — lines on both sides. Split on this reading:
  * a legacy-side hunk that is a **call-site seam** — the mechanical adaptation a legacy caller needs
    to keep compiling against a changed new-arch signature — is **kept with the commit**. It is not
    new work in a doomed crate; it dies with the crate, and dropping it would only break the build
    before the deletion lands.
  * a legacy-side hunk that carries **behaviour or its cells** is **dropped**, and the commit is
    re-cut with the new-arch half only (**SPLIT**).
  * a commit that only makes sense with both halves is **dropped whole** and recorded.

`busbar-substrate` and `busbar-substrate-values` are **not** on the deletion list
(`D33-legacy-retirement.md` §5: both already carry zero `busbar_core::` reach and no Cargo edge to
it), so substrate work is NEW-ARCH.
