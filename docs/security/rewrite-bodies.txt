2bc50d2cb	Restores the WHATWG basic URL parser's leading/trailing trim (C0 controls and space) ahead of the existing interior tab/LF/CR strip, so this trust-boundary host guard reads a URL exactly as the connecting HTTP stack will. The extraction that split this guard out from its substrate sibling kept only the interior-character half of that first step; a leading space hid the scheme ("` http://169.254.169.254/`" fails the scheme match and is waved through with no host ever examined) and a trailing space changed the parsed host ("`https://10.99.99.99 `" matches no configured block-list entry while the dialing stack trims the space and connects to the bare address). Both spellings are legal inside an unquoted YAML scalar or a console copy-paste. The endpoints reached through this guard POST operator client credentials to the resolved host, so a host the guard fails to recognize as blocked is a host that receives those credentials -- an SSRF-to-credential-leak path toward cloud metadata services and other denylisted hosts. Fixed by trimming first, in the parser's own order, byte-for-byte the same predicate the live sibling copy uses, plus parity tests ported from that sibling's own coverage.

d747f5831	Fixes a mutation rate limiter bypass triggered by a wall-clock regression (an NTP step backwards, or a container starting before its host's clock syncs). The limiter keyed its sweep on exact window equality (`*w == window`): a single request carrying an older `now` recomputed an older window and cleared every live counter in the map, regardless of principal or class, handing any principal a fresh budget for the current window. Because the admin mutation limiter is what caps the blast radius of CONFIG-class mutations (10/minute), this made that cap bypassable by anything able to nudge the observed clock backwards. Fixed by keying the limiter's high-water mark on the newest window it has ever judged (monotonic, via `max`), judging a regressed `now` against that high-water mark instead of opening an older window, and sweeping only entries strictly older than the window being judged -- so a backwards clock step can lengthen the current window but can never refill a spent budget or wipe a live counter.

fcfcafb16	Adds the single, shared runner for kernel-held durable ("PlaneRecord") legs, validating a leg's declared schema, its operation within that schema, and its body size against the record ceiling before any leg reaches a sink. Before this runner existed, a call site could hand a leg straight to a sink; the schema/operation declaration on the calling plane and the size ceiling on a record's body were both controls that had to be re-implemented (or omitted) at each call site rather than enforced once. Centralizing validation ahead of the sink closes that gap: an undeclared schema, an operation a schema does not declare, and an oversized body are now refused in one place, with distinct refusals (undeclared schema vs. undeclared operation vs. oversize vs. sink failure vs. a dead capability) so an operator reading a refusal is told which control fired rather than being handed an opaque failure.
